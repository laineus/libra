01 / 主线剧情

游戏流程

帮助居民解决烦恼并收集苹果，与艾米丽共度时光，逐步深入梦境世界。

在探索地点与艾米丽等待的房间之间往返

  1. 解决居民的烦恼，获得苹果
    与各地居民交谈可以开始任务。完成委托后会获得苹果作为谢礼，探索地点和任务顺序可以自由选择。
  2. 把苹果交给艾米丽，提升魅力
    回到房间，把苹果交给艾米丽并与她共度时光。选项的区别请参阅魅力的提升方法。
  3. 探索新开放的道路
    心灵魅力与身体魅力的合计值是部分道路的通行条件。合计达到1、3、10时，可以重新查看之前无法通过的道路。
  4. 在特定地点推进主线
    探索途中到达特定地点会触发主线事件，有些道路也会随事件开放。因此既要通过任务提升魅力，也要推进剧情。
魅力的提升方法

01 / 主线剧情

魅力的提升方法

魅力分为心灵魅力和身体魅力。不确定如何选择时，让两者均衡提升即可。

把苹果交给艾米丽

把任务中获得的苹果带回房间。与艾米丽交谈并选择“交出苹果”后，会出现两个选项。

  • “想散歩”：心灵魅力增加1。
  • “想一起睡”：身体魅力增加1。

无论选择哪一个都会消耗1个苹果，魅力合计增加1。当前数值可在菜单的状态页面确认。

均衡提升两种魅力

开放道路所需的是两种魅力的合计值，但两者的分配会影响后期的结局选项。

没有特别偏好时，可以交替选择散步和一起睡。建议达到心灵魅力5、身体魅力5，这样既能以合计10推进后期，也能选择两个结局。

即使有所偏向，也可以继续交苹果提升较低的一方。最后前往心脏之前，请确认两者都达到5。

攻略流程

01 / 主线剧情

攻略流程

从开场教学开始，经由脑的事件，再次前往心脏为止的流程。任务可以按喜欢的顺序完成。

主线流程

  1. 在森林2完成教学。
    按照提示学习移动、交谈和拾取物品。拿到苹果后回到引导者身边再次交谈，结束教学。
  2. 穿过森林回到房间，与艾米丽见面（魅力合计0→1）。
    从森林2向东进入森林1，再向北到胃。从北侧中央附近进入房间，把教学中得到的苹果交给艾米丽。魅力合计达到1后，胃西侧通往洞窟2、东侧通往冰洞1的道路开放。
  3. 探索森林、冰洞、洞窟等区域，把魅力提升到3。
    完成居民委托，再把2个苹果交给艾米丽。暂时无法完成的任务可以以后再做。合计达到3后，胃东北侧的道路开放。
  4. 从胃东北侧继续前进。
    沿途观看事件并向北走，到达十字路口后继续推进事件。
  5. 从十字路口北侧的东边道路前进。
    先进入东边道路观看事件。之后西边道路和豪宅区域的新出口会开放。
  6. 在秋季、豪宅、矿坑、医院等区域完成任务（目标：魅力合计10）。
    秋季1向北是豪宅1，向东是矿坑1，向西是秋季2；秋季2西侧通往医院1。完成任务并把魅力提升到10。
  7. 从墓地北侧前往脑。
    从医院1向北进入病院2，再向北到墓地。魅力合计达到10且完成此前的主线事件后，可以从北侧进入脑。
  8. 按需完成剩余任务并调整魅力分配。
    脑事件后不需要继续提高魅力合计。若要完成其他任务，可以在这里巡游各地。结局所需分配请参阅魅力的提升方法。
  9. 再次前往心脏。
    准备好后回到十字路口，从东北侧进入心脏，剧情将继续。
结局分支

01 / 主线剧情

结局分支

游戏有两个结局。本页不涉及剧情核心，只介绍如何让两个选项都可以选择。

心灵魅力与身体魅力分别达到5以上

两种魅力都达到5以上时，后期可以从两个结局选项中自由选择。任何一项低于5时，只能选择其中一个。

即使合计为10，若是7和3这样的分配，也无法选择两个结局。想保留两个选项时，请以5和5为目标。

最后前往心脏前确认

在菜单状态页确认两种魅力。若有不足，把苹果交给艾米丽提升较低的一方即可。具体方法请参阅魅力的提升方法。

通关后

01 / 主线剧情

通关后

以“沉眠”结局通关后，可以继续探索，也可以邀请艾米丽同行。

和艾米丽一起外出

通关后在房间与艾米丽交谈，会出现“跟我来”选项。选择后，她会陪你一起在各地行走。

同行不会增加或改变其他事件。回到房间后同行结束，之后可以再次邀请。

继续完成剩余任务

通关后不会开启新的主线或追加任务，但可以继续完成尚未结束的任务。

也可以继续收集绘画等物品。通关后出现的绘画请参阅绘画位置一览。

02 / 任务

为生存而拼尽全力的两人

接受地点：森林3・东北侧的树妖

需要准备：1只大力神独角仙

完成步骤

  1. 与森林3的树妖交谈并听取委托。
  2. 在森林寻找并捕捉大力神独角仙，例如森林4有时会出现。普通独角仙不能代替。
  3. 把大力神独角仙放在背包里与树妖交谈，先让他确认。
  4. 与同一地图西南侧的青蛙交谈，把大力神独角仙交给他。
  5. 回到树妖处报告，即可完成并获得苹果。

补充

捕捉后不要忘记先给树妖看。最后报告时选项会改变对话，但两者都能完成任务。

恋人的幸运草

需要准备：1个幸运四叶草

完成步骤

  1. 与森林4的青蛙交谈，询问他在找什么并接受委托。
  2. 在森林的三叶草丛中寻找幸运四叶草。它和普通三叶草是不同物品。
  3. 把幸运四叶草放进背包并交给委托人。

补充

幸运四叶草有时会在森林2～5出现。找不到时先探索其他地方，再回来查看。

02 / 任务

蛇与青蛙的天平

接受地点：洞窟1・东北侧的蛇

需要准备：蓝宝石、绿宝石、紫水晶、红宝石各2个

完成步骤

  1. 与洞窟1的蛇交谈，确认交换条件。
  2. 用手枪破坏洞窟或矿坑中的宝石岩，收集4种宝石各2个。手枪可在军事基地取得。
  3. 把共8个宝石放进背包，与蛇交换。

补充

放在房间的宝石无法交付，请确认背包中每种数量都足够。

诅咒的方法

接受地点：洞窟3・东北侧的蝙蝠

需要准备：诅咒人偶

完成步骤

  1. 从洞窟2的青蛙处拿走诅咒人偶。
  2. 把诅咒人偶放进背包，与洞窟3的蝙蝠交谈开始任务。
  3. 与出现在森林2的树妖交谈，听取关于诅咒的说明。
  4. 若想获得苹果，不要执行诅咒。回到洞窟3向蝙蝠报告。报告时选择哪项都能得到苹果。

补充

执行诅咒后也可以通过报告完成任务，但不会得到苹果，结局也会更加沉重。

02 / 任务

建立在牺牲之上的英雄

接受地点：病院2・东北侧的医生企鹅

不擅长恐怖演出时，可以不接受并跳过此任务。主线仍可推进，但以此任务完成为条件的请让我们永远在一起也无法进行。

需要准备：无

完成步骤

  1. 听取病院2东北侧医生的委托。之后的问题选择哪项都可以。
  2. 在病院2（里）与东北房间里的4人全部交谈。
  3. 再与之后出现在南侧的人交谈。
  4. 按附近的照明按钮回到原来的医院，与医生交谈到最后。再次出现问题时，可以保持原答案，也可以改变答案，两者都能完成。

补充

任务中包含恐怖演出，且地图菜单的移动会受到限制。完成后可用照明按钮在医院表里之间往返。

02 / 任务

光合作用的味道

接受地点：宇宙・谈论食物的外星人

需要准备：咖喱饭、牛排、炒青菜、蛋包饭各1份

完成步骤

  1. 参考前往宇宙的方法前往宇宙。
  2. 与谈论食物的外星人交谈，把两种问题都选择一次，开始任务。
  3. 通过艾米丽的料理收集咖喱饭、牛排、炒青菜和蛋包饭。

不必一次凑齐，可以获得一种就交一种。曲奇饼、便当和鳗鱼饭不算在内。

03 / 任务相关

杀害居民

杀死可以交谈的居民后，将无法继续与该居民有关的任务。开枪前请确认目标。

确认头上的对话图标

有些居民的外观与野生生物很相似。使用枪械前，请确认头上是否有对话图标、对方是否能交谈。

误射后，在杀死前离开地图

射中居民后会暂时无法交谈。只要对方还活着，停止攻击，移动到其他地图后再回来，就能重新交谈。

若已经杀死，也有救济措施。具体步骤请参阅复活居民。

有些任务会要求杀人

部分任务的流程中会特意要求杀死居民，此时请按照委托和对话推进。

任务剧情造成的死亡有时无法复活，相关任务整理在复活居民。

03 / 任务相关

破坏物品

部分物品被枪破坏后，里面可能会出现其他物品。

破坏岩石

洞窟和矿坑中有两种不同的岩石块：一种会出现宝石，另一种会出现化石部件。两者外观不同，请按需要寻找。

破坏冰

破坏冰洞区域等地的冰，有时会出现鱼或罕见生物。详情请参阅稀有物品。

03 / 任务相关

组装化石

化石不只是收集品，把部件按正确位置摆放后可以组装。

收集7种部件

破坏洞窟或矿坑中如下图所示的岩石块，有时会出现化石部件。它与普通石头和宝石岩不同。手枪可在军事基地取得。

需要化石（头）、化石（身躯）、化石（右手）、化石（左手）、化石（右足）、化石（左足）、化石（尾巴）各一个。重复部件无法替代缺少的种类。

在背包或地面按完成形状摆放

集齐后，在背包内或地面上像拼图一样摆放，在房间也可以组装。

身体放在中央，头放右上，尾巴放左边，手放在身体上方，脚放在下方。参照完成图微调重叠位置。

位置正确后，部件会自动合并成一个恐龙化石。失败时请检查左右手脚是否放反。

完成后的用途

完成组装时会解锁考古学家。完成品可以交给上古的浪漫的委托人，也可以留在房间装饰。

不可逆要素

汇总因任务选项或物品处理而无法事后恢复的内容。

魅力

已经提升的魅力无法重新分配。若想选择两个结局，心灵魅力和身体魅力都必须达到5以上。

任务共有15项，加上教学奖励最多能获得16个苹果。若把12点以上投入其中一项，仅靠这些苹果就无法把另一项提升到5。若执行诅咒等原因没有取得任务奖励，余量还会更少。

想保留两个结局时，请优先把两项都提升到5。若分配偏斜而确实缺少苹果，森林2的额外苹果是救济措施。

任务结局

大多数任务可以自由选择喜欢的选项，但一旦结局确定，之后无法改为其他发展。完成后居民的台词也会固定为所选路线对应的内容。

结局后的存档

在结局后存档，该存档便无法再观看另一个结局。通关后继续提升魅力也不能重新选择。

想观看两个结局时，请保留两种魅力都达到5以上的通关前存档。结局后的进度请保存到其他栏位，不要覆盖该存档。详情请参阅结局分支。

在“诅咒的方法”选择死亡路线

诅咒的方法可以在居民存活的情况下完成。但若真的执行诅咒，居民会死亡，复活也无法使其恢复。想走生存路线时，不要执行诅咒，直接回去报告。

买回《努力的矿工》后再次遗失

在宅邸里的孩子交出的《努力的矿工》可以用宝石换回，但只能换回一次。之后若遗留在屋外或破坏掉，就无法再次获得。

若尚未解锁绘画收藏家，遗失后该存档便无法集齐23幅绘画。最初交给矿工前若遗失，则可以从委托人小孩处再次领取。

遗失安东尼的信

在海怪中根据选项可能获得安东尼的信。遗失后不会补发。想选择交信路线时，请拾取并保管到向渔夫报告为止。

无论哪个结局都能完成任务并获得苹果，不会影响任务或成就完成。

艾米丽对物品的反应

放在房间的物品评论每种反应只能听一次。重新摆放同一物品也不会再次出现。有些物品共享反应，部分组合则有另一种反应。

一次摆放很多绘画可能会错过少量绘画时的反应。想全部听到时，可按1幅、10幅、23幅的顺序逐步增加。组合示例请参阅艾米丽的特殊反应。

纸巾

纸巾的摆放位置会改变艾米丽的反应和房间事件。
